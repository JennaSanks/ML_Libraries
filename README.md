# Machine Learning Libraries

This repository contains a collection of Jupyter Notebooks demonstrating the fundamentals of popular Python libraries used in Machine Learning and Data Science. Each notebook introduces the core concepts, commonly used functions, and practical examples for a specific library, making it a useful learning resource for beginners.

---

## Features

- Beginner-friendly tutorials
- Hands-on examples for each library
- Well-organized Jupyter Notebooks
- Covers essential Machine Learning and Data Science libraries
- Easy to understand and modify

## Installation

Clone the repository:

```bash
git clone https://github.com/JennaSanks/ML_Libraries.git
cd ML_Libraries
```

Install Jupyter Notebook if it is not already installed:

```bash
pip install notebook
```

Install the required libraries:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn tensorflow keras torch
```

---

## Running the Notebooks

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open any notebook and execute the cells sequentially to explore the concepts and examples.
